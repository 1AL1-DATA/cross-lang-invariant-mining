The boolean-tag vocabulary was replaced with **CFG topology hashing** (control-flow subgraph isomorphism). ## Outstanding Limitations

1. **No per-language test harnesses** for Rust/Go/Haskell/OCaml/TypeScript. Validation is at compilation level only.
2. **Haskell has no CFG subgraphs** in the current corpus. Its binary search uses pattern guards, which the IR lowerer does not yet encode as CFG nodes. The fix would require extending the Haskell AST→IR mapping to recognize guard expressions as BRANCH nodes.
3. **Corpus generated by single model/prompt.** Generalizability across models and prompt styles is untested.
4. **CFG hasher is position-sensitive.** Canonical labeling (e.g., Weisfeiler-Lehman) would better handle isomorphic graphs with different branch ordering.
5. **Phase 2 was not re-run.** Implementations are from the original Ollama run.

## How to Fix This (for future runs)

1. Implement per-language test harnesses for Rust/Go/Haskell/OCaml/TypeScript.
2. Extend Haskell IR lowering to encode pattern guards as BRANCH nodes.
3. Re-run Phase 2 with the fixed pipeline (provider-agnostic, validated test generation).
4. Add canonical CFG labeling (WL-kernel or similar) for perfect isomorphism.
5. Test corpus generalizability by varying model and prompt variant.

## Lessons Learned

- **Scaffolding ≠ data.** A well-structured pipeline with no validated outputs is still an empty pipeline.
- **Controls must run first.** The negative control is the most important check; skipping it means the invariant vocabulary is unvalidated.
- **Test validation must be wired in, not stubbed.** "The test harness exists in another file" is the same as "there is no test harness."
- **Synthetic data files will be cited.** If `synthetic_results.json` exists, someone will use it.
- **Sample size bugs compound.** A 2× N inflation from a glob bug invalidates every downstream statistic.
- **AST parsers need structural containers.** Empty-text nodes in tree-sitter trees are structural, not noise — dropping them destroys the AST for languages that use block delimiters.
- **IR lowering must handle language-specific body wrapping.** Python uses BLOCK; TypeScript/Haskell/Go/Rust don't.
